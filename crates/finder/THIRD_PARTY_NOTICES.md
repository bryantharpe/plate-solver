# Third-party notices: finder

The `finder` binary embeds its web page (`web/dist/`, built from `web/`) and its sky data
(`data/`). Those include the third-party works below, each under its own license; none of them
is covered by this project's own license. `finder --licenses` prints this file.

## In the web page (`web/dist/`)

| Component | Version | License |
|---|---|---|
| [React](https://github.com/facebook/react) (`react`) | 19.3.1 | MIT |
| React DOM (`react-dom`) | 19.3.1 | MIT |
| `scheduler`, used by React DOM | 0.28.0 | MIT |
| [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss), the generated stylesheet | 4.3.3 | MIT |
| [Vite](https://github.com/vitejs/vite), runtime helpers it adds to the build | 8.3.4 | MIT |
| [Archivo](https://github.com/Omnibus-Type/Archivo) font, via `@fontsource-variable/archivo` | 5.3.0 | OFL-1.1 |
